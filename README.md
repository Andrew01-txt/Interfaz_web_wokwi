# Interfaz_web_wokwi
Monitoreo (ESP32 Frontend): A1 mover el DIP Switch, la ESP32 publica el estado. La interfaz 10 recibe y actualiza el displayvirtual. Control (Frontend ESP32): A1 presionar un botón en la interfaz, se publica un número. La ESP3210 recibe y 10 muestra en el displayfísico.
